# 🎮 坦克大战 (Tank Battle)

一个使用纯 HTML/CSS/JavaScript 实现的经典坦克大战游戏。

## 🕹️ 游戏玩法

- 控制你的坦克，保护基地🦅
- 消灭所有敌方坦克即可过关
- 每关敌人数量和速度都会提升
- 基地被摧毁则游戏结束

## 🎯 操作说明

| 按键 | 功能 |
|------|------|
| `↑↓←→` / `WASD` | 移动坦克 |
| `空格` / `J` | 发射子弹 |
| `P` | 暂停/继续 |
| `R` | 重新开始 |
| `Enter` | 开始游戏 |

## 🗺️ 地图元素

- 🧱 **砖墙** - 可被子弹摧毁
- 🛡️ **钢墙** - 无法被摧毁，子弹会反弹
- 🦅 **基地** - 必须保护的核心，被摧毁则游戏结束

## 🚀 如何运行

直接在浏览器中打开 `index.html` 即可开始游戏。
